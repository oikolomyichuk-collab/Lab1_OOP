Лабораторна робота 1

SmartPhone Manager (C# Console App)
Консольна програма для роботи з об"єктами класу Smart (смартфони). Реалізовано створення та збереження об"єктів, перевірку коректності введення, пошук, видалення, демонстрацію поведінки класу та роботу з переліком enum.

Функціонал програми:
створення об"єктів класу Smart з перевіркою обмежень при введенні;
зберігання до N смартфонів (значення задає користувач);
перегляд усіх смартфонів у табличній формі;
пошук смартфонів за брендом;
демонстрація поведінки (дзвінок, фото, інтернет, температура);
видалення смартфону за індексом;
порівняння камери двох смартфонів;
збільшення ОЗУ існуючого смартфону;
меню взаємодії з користувачем.

Структура файлів проєкту

Program.cs — головний файл, містить меню і логіку обробки введення користувача.
Smart.cs — клас смартфону, поля, властивості з обмеженнями та реалізовані методи.
Smartphone.cs — перелік enum, який визначає тип смартфону (Weak, Average, Powerful).

Клас Smart — характеристики та обмеження

Клас має закриті поля та публічні властивості, кожна з яких перевіряється при встановленні значення.
Brand: текст від 3 до 12 символів.
Model: текст від 2 до 12 символів.
OzyGB: число від 0 до 512.
CameraMPx: число від 1 до 264.
Type: значення enum SmartphoneType.
Об"єкт створюється лише у випадку, якщо всі параметри відповідають умовам. При порушенні — викидається повідомлення про помилку.

Реалізовані методи класу
Функції поведінки смартфону:
Call() — імітація дзвінка.
Photo() — імітація фотографування.
Internet() — вихід в інтернет.
Temperature() — повідомлення про нагрівання.

Функціональні методи:
ShowInfo() — виведення даних про смартфон.
UpgradeRAM(int extraGB) — збільшення ОЗУ, якщо не перевищено 512 ГБ.
CompareCamera(Smart other) — порівняння камер з іншим смартфоном.

Лабораторна робота 4

Проєкт реалізує консольну програму для роботи з обєктами класу Smart.  
У цій версії додані static поля, static властивості, static методи Parse і TryParse, а також перевизначений метод ToString.  
Програма продовжує Lab-3 і відповідає вимогам лекції 4.

Структура проєкту
Smart.cs – опис класу Smart. Містить приватні поля, властивості, конструктори, static поля і методи, перевизначення ToString.  
Smartphone.cs – перелік SmartphoneType з трьома значеннями Weak, Average, Powerful.  
Program.cs – консольне меню, робота з колекцією смартфонів, виклики static і екземплярних методів.

Static поля і властивості
У класі Smart додані два static private поля
- count – лічильник коректно створених обєктів класу Smart  
- category – назва категорії товару "Електроніка"

Для доступу до них зовні оголошені static public властивості
- Count – тільки для читання, повертає кількість створених обєктів  
- Category – тільки для читання, повертає поточну категорію
Лічильник count збільшується у конструкторах після успішного створення обєкта.  
Таким чином Count відображає реальну кількість створених смартфонів.

Static методи
У класі Smart реалізовані такі static методи
- GetCategory() – повертає рядок з назвою категорії товару. Відповідає предметній області, оскільки всі смартфони належать до однієї категорії.
- Parse(string s) – перетворює рядок s на обєкт Smart.  
  Рядок має містити чотири частини  
  brand;model;ozyGB;cameraMPx  
  При помилці формату або неможливості перетворення числових значень генерується відповідний виняток FormatException з інформативним повідомленням.
- TryParse(string s, out Smart obj) – намагається перетворити рядок на обєкт Smart.  
  Усередині викликає Parse.  
  У разі успіху повертає true і заповнює змінну obj.  
  У разі помилки повертає false і встановлює obj у null, при цьому виняток не викидається назовні.

Метод ToString
У класі перевизначено public override string ToString().  
Метод повертає рядок у форматі
Brand;Model;OzyGB;CameraMPx
Цей формат узгоджений з методом Parse і може використовуватися для збереження або логування обєктів, а також для подальшого відновлення через Parse або TryParse.

Методи екземпляра
З Lab-3 збережені всі екземплярні методи

- Call() і перевантажений Call(string number)  
- Photo()  
- Internet()  
- Temperature()  
- GetInfo()  
- UpgradeRAM(int extraGB)  
- CompareCamera(Smart other)
Метод UpdateType залишається приватним і оновлює властивість Type при зміні ОЗУ.

- виводиться значення Smart.Count як кількість створених обєктів

Використані атрибути MSTest
У тестовому проекті застосовано атрибути
TestClass – позначення класів, що містять тести  
TestMethod – позначення окремих тестових методів

TestCleanup – очистка після виконання тесту  
DoNotParallelize – заборона паралельного виконання для тестів лічильника, щоб результати для Count були коректними

Шаблон AAA
Усі тестові методи побудовано за шаблоном AAA
Arrange – підготовка даних, створення обєктів Smart з потрібними параметрами  
Act – виклик тестованого методу або властивості  
Assert – перевірка результату за допомогою методів класу Assert
Використані методи Assert
AreEqual – порівняння очікуваного та фактичного значення  
IsTrue та IsFalse – перевірка логічних результатів (успіх TryParse)  
IsNotNull та IsNull – перевірка створення або відсутності обєкта  
ThrowsException – перевірка генерації FormatException у Parse при некоректному рядку

Покриття нестатичних методів
Перевіряється логіка роботи всіх основних нестатичних методів класу Smart

Photo, Internet, Temperature – повернення правильних текстових повідомлень

CompareCamera – три сценарії порівняння камер  
ToString – правильний формат рядка brand;model;ozyGB;cameraMPx  
GetInfo опосередковано перевіряється через достовірність властивостей
Окремими тестами перевіряються гетери властивостей Brand, Model, OzyGB, CameraMPx.

Покриття static методів і полів
Перевіряються такі static елементи
Parse – успішний розбір коректного рядка і генерація FormatException у разі некоректного формату  
TryParse – успішне і неуспішне перетворення рядка на обєкт Smart без викидання винятків  
GetCategory – повернення правильного рядка з назвою категорії товару  
Count – коректне збільшення лічильника при створенні обєктів  
ResetCountForTests – скидання лічильника перед тестом Count

Видаляє елемент з колекції за індексом.

Якщо індекс виходить за межі колекції, нічого не видаляє і повертає false.
